# Week 3 — AI-Assisted Web Development & Web Security

This week focuses on **AI-assisted web development** and understanding how modern full-stack web applications are built, tested, secured, and deployed.

The sessions cover the complete application workflow — from generating and developing the user interface to connecting databases, backend services, authentication, third-party integrations, and deployment.

---

## Topics Covered

### AI-Assisted Web Development

- Understanding AI-assisted web development
- Using AI app builders to scaffold web applications
- Using AI coding agents inside an IDE
- Moving from AI-generated prototypes to local development
- Reviewing and improving AI-generated code
- Unit testing and smoke testing

### Modern Web Development Stack

The session introduced a modern full-stack development workflow using:

- **V0** — AI-assisted application generation and prototyping
- **Next.js** — Full-stack JavaScript/TypeScript framework
- **React** — Reusable user interface components
- **Tailwind CSS** — Application styling
- **Supabase** — Managed PostgreSQL database, authentication, and storage
- **Git & GitHub** — Version control
- **Vercel** — Application deployment and hosting
- **Stripe** — Payment integration

---

## Full-Stack Application Architecture

```text
User
  ↓
Browser / Frontend
  ↓
Next.js Application
  ↓
Backend / API
  ↓
Authentication & Authorization
  ↓
Database / External Services
```
